# Where the bundled themes come from

The `.svg` files in this folder are the scenes of Claude Code's `theme-examples` plugin, version **0.6.0**
(`github.com/anthropics/claude-plugins-official/tree/main/plugins/theme-examples`, read on 2026-11-27), by
Anthropic, licensed under the **Apache License, Version 2.0**. The full text is in
`LICENSES/theme-examples.Apache-2.0.txt`. The plugin ships no NOTICE file of its own.

Each scene is copied **unchanged**: `scripts/themes-bundle.mjs` runs the plugin's `scene()` function for the theme and
writes exactly the SVG it returns, with no edit, no formatting and nothing added. (The gate's rule for reduced motion
is put into a scene when it is served or installed, never into these files.) Run `npm run themes:bundle` to write them
again; the script stops if this notice does not name the version it copied.

What OpenLen takes, and what it does not (spec local 2026-11-27-temas-del-workspace, decision 5):

- The 20 themes that have no shader (honu-lagoon, koi-mosaic, halftone-dawn, halftone-dusk, plotter-tide,
  plotter-tide-night, dither-dunes, dither-dunes-night, paper-garden, paper-garden-kraft, night-reef, snow-pines,
  braille-stars, teletext-clouds, vector-range, departure-board, blueprint, deep-water, aurora, ember).
- Of the nine pictures a shader plays over in Claude Code (duck-pond, falling-sand, field-lines, garden-beetles,
  koi-pond, ripple-tank, sea-sparkle, semicolony, star-chart), only the still SVG of the light entry. OpenLen plays no
  shader and no sound, so a still is all of them that is here, and the dark entry of each is not bundled.
- The `id`, the `window`, the `glass` and the `blurb` of each theme as the plugin declares them, and its `title` as the
  English title. A `twin` is kept only where both entries of the pair are bundled.

Not taken: the plugin's commands, hooks, fireworks, sounds, shaders and types.

The index (`index.ts`) is generated by the same script.
